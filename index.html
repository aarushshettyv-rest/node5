Three sharp tools.

Everything you need for a small site or a quick local experiment, with Bun doing the heavy lifting underneath.

01 / SERVE

node5

Serve one HTML file or an entire folder with assets, nested indexes, compression, and smart caching.

02 / INSTALL

n5pm

Install packages through Bun's native resolver, with offline mode, timing, and honest errors.

03 / EXECUTE

n5px

Run local binaries and scripts from your project without reaching for a global install.

One minute setup

Start with a folder.

Install Bun, clone the project, and let the runtime do the boring parts. The rest is yours.

# install Bun
bun --version

# get Node.5
git clone https://github.com/aarushshettyv-rest/node.5
cd node.5
bun install
bun link

# serve your site
 node5.js ./site --port 3000
